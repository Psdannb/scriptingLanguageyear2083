What is DOM?

DOM (Document Object Model) is a programming interface that represents an HTML or XML document as a tree of objects. It allows JavaScript to access, modify, add, or delete elements and content on a web page dynamically.

JavaScript can use the DOM to Change HTML content, Change CSS styles,Add new elements,Remove elements,Handle events (click, submit, etc.)
