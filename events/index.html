What is Event Handling?

Event handling is the process of detecting and responding to events that occur in a web page. An event is an action performed by the user or browser, such as clicking a button, pressing a key, submitting a form, or loading a page. JavaScript uses event handlers to execute specific code when an event occurs.

Listening for Events:

Listening for an event means waiting for a particular action to occur on an HTML element. JavaScript provides the addEventListener() method for this purpose.

Syntax: element.addEventListener("event", function);

Some of the events are :click,mousemove,mouseover,mouseout,dblclick,DOMContentLoaded,load,keydown,keyup,scroll, submit etc

Reacting to Events:

Reacting to an event means performing an action when the event occurs.

What is preventDefault?

preventDefault() is a method of the Event object that is used to stop the browser's default action associated with an event.

Removing an Event Listener

The removeEventListener() method is used to remove an event listener that was previously attached to an element using addEventListener(). This prevents the event handler from executing when the event occurs.

syntax:element.removeEventListener("event", functionName);

Here : "event" → Event type (e.g., "click", "submit") functionName → The function that was attached as the event handler
