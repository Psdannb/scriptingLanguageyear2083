Introduction to Cookies

A cookie is a small piece of data stored by a web browser on the user's computer. Cookies are used to remember information about a user and maintain state between different web pages and browser sessions.
Since HTTP is a stateless protocol, a web server cannot remember previous requests from the same user. Cookies help solve this problem by storing user-related information in the browser and sending it back to the server with future requests.

Common uses of cookies include:

  • User authentication
  • Remembering login information
  • Storing user preferences
  • Tracking user activity
  • Maintaining shopping cart information

Cookie Structure

A cookie consists of several attributes: name=value; expires=date; domain=domain-name; path=path-name
Example: username=Ram; expires=Fri, 31 Dec 2027 12:00:00 GMT; domain=example.com; path=/
